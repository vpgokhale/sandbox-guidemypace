Guide My Pace

An accessibility tool that does not store or collect any personal data from the responses or exported PDF.

Your browser doesn't support live speech recognition (the Web Speech API), so it can't listen and check your answers — this is a Safari limitation (Safari has never implemented this API, on desktop or iOS). Reading prompts aloud (text-to-speech) still works here, but for the full experience — listening to you read questions and answer choices — use Google Chrome or Microsoft Edge on desktop, with an internet connection and microphone access.

Reading Tracker

Setup Reading Tracker

  • Load a passage as a PDF (a scan or photo works too)
  • Every word gets a grey dot underneath
  • Tap a dot, then read just that word aloud; the dot turns blue once it is recorded (tap it again to redo it)
  • Stuck? Tap the word itself to hear it read aloud (it is counted as help)
  • When you are done, press Score my reading: words are colored like the Q&A Form, and accuracy counts words read right without help
  • Want fewer distractions? Turn on Cover unread text below to show only the part you are reading
  • Use Save results for a PDF or CSV report
  • Needs a microphone and Google Chrome or Microsoft Edge.

i
For faster readers (90 words a minute or more), where tapping a dot for every word is too slow. Your first tap turns the microphone on and it stays on until you press Stop listening (or 10 minutes pass). Tap the dot under the word where you are starting, then tap again at the start of each new phrase or line as you read. Afterwards, what was heard is matched to the words between your taps. Turning this on sets Word Cover to 0 and Line Cover to 2 so the next dot is within reach. Guide My Pace does not save any audio, but your browser’s speech service is listening the whole time the microphone is on.

Reading Flashcards

Setup Reading Flashcards
  • Load a CSV file with three columns: category, word and reveal
    • One row per card
    • Each category gets its own color
  • Tap to reveal shows the reveal text (e.g. breaks down syllables)
  • Each session uses the number of cards you set
    • ones seen the least first
    • everything gets practice over several sessions.
  • Press Start, read each card aloud, and it moves on by itself
  • Accuracy is recorded for every card and every category
  • Your progress is kept on this device
  • Use Save session & progress for a backup file

    • Load the answer key (an Excel or CSV file with the sentence as printed and the sentence corrected).
    • Pick a day, then fix one sentence at a time.
    • Click on each underlined word, make edits, check.
    • Scroll to the right for full sentence.
    • The hint above the sentence tells you what to look for.

    Setup Q&A Form

    Voice:
    i
    Used whenever the app reads a question, answer choice, or word aloud. Shows up to 3 female and 3 male voices — the most commonly used English (US) voices already built into this device, not fetched over the network. Leave it on "Device default" to let the browser pick, or choose one so the voice stays the same regardless of which one your browser happens to default to.
    i
    In Speaker Mode, plays a recording of a real voice instead of the computer voice wherever one exists for a question, passage or answer choice. Anything without a recording is read by the usual voice. Recordings are made with “Record my voice for this test” and are saved on this device only. A voice pack file carries them to another device.
    i
    Check this to add short reward breaks between questions. You then choose a Reward File (a PDF) and how many correct answers earn each reward. Unchecking it removes the loaded reward file.
    i
    Offers a reward after this many correct responses. Only works when a Reward File is loaded. Every time that many multiple-choice answers with an answer key have been checked and are right (counted from the last reward), a reward page from the Reward File is placed before the next question. It is written like a short-answer question in a PDF, and it works like any other question (reading aloud, cover text, recorded voice, notes). Several rewards in the file are used in order, then start over. Pressing Previous never goes back to a reward page. Whole numbers from 1 up to the number of questions.
    Speed:
    i
    Speaker Mode will enable all text to be read aloud. Reader Mode will listen for the reader's own speech. In either mode, the same flow applies — answer choices only unlock once the question has been processed, and each choice must be processed before a selection can be made. Speeds below 1× also slow the voice and add a pause between words — the slower the speed, the longer the pause.
    i
    Experimental. When checked, Speaker mode breaks what it reads into short phrases with a brief pause between each one, instead of one continuous sentence — closer to how a person naturally reads aloud. Off by default; only affects Speaker mode's own TTS playback.
    i
    Checked (default): when the reader says a wrong word, the device says the right word so the reader can repeat it. Uncheck it to turn that off: the device stays quiet, the reader gets a second try, and a second wrong try marks the word incorrect. The Helper mode prompt after silence below is separate.
    i
    Unchecked (default): the reader can still always click the current word for help manually. Check this to also have the device prompt automatically: if the reader hasn't said the current word after the number of seconds you choose (1 to 5, default 1), the device says it aloud, and if it's still not resolved after the same number of seconds again, it moves on so the reader is never stuck waiting. Only available in Reader Mode.
    Target WCPM:
    i
    When checked and Speaker mode is off: before listening for each short phrase (2–3 words), the device reads it aloud first at the pace set by Target WCPM, then the reader repeats it back — marked "correct after choral prompt" rather than plain correct. Off by default.
    Block color:
    i
    Blocks out the rest of the line and every line below it — in the passage and in the question stem — so only what's already been read stays visible. Answer choices stay fully covered until played, then follow the same settings. Applies in both Speaker mode and Read/listen mode.
    Reader Mode Word Cover: Reader Mode Line Cover:
    i
    Word Cover counts the current word as 1: 1 shows only the current word, 2 also shows the next word, and so on. 0 turns the word cover off, so the whole current line stays visible. Line Cover works the same way for lines: 1 shows only the current line, 2 also shows the line below it, and so on. Raise these gradually to fade the cover back as the reader needs less support.
    i
    When checked, any exact phrase (two or more words) shared between the current question and the passage is highlighted in purple in the passage.
    i
    When checked, if the selected answer proposes an edit ("before → after"), the passage text is overwritten live to preview it.
    i
    Controls Keyword Match (the blue underline on an answer choice that echoes your notes). Unchecked (default): matching ignores letter case and punctuation entirely — "c" in your notes also matches "C", and "stops" in your notes matches "stops." or "stops," or "stops;" in an answer choice, since only the letters/digits are compared. Check this for an exact, character-for-character match — same case AND the exact same punctuation required — most useful for a punctuation/capitalization-fix worksheet where that's exactly what's being tested.
    i
    For "find and fix the mistake" worksheets (punctuation, capital letters, wording). Edit Mode turns on two things together. Mark Up: when the answer you select proposes an edit ("before → after"), the passage text is changed live so you can see the fix in place, and it goes back the moment you pick a different answer. Notes - Exact Match: the Keyword Match underline (the blue underline on an answer choice that echoes your notes) then needs an exact, character-for-character match, the same letter case and the same punctuation, instead of ignoring case and punctuation. Leave it off for ordinary questions.
    i
    On by default. When checked, once every question has an answer (and you've pressed Check my answer on the last question) your final score is shown right above the Submit & export button as a fraction and a percentage. Only questions with an answer key can be scored.
